# haywoodmarx/tap

Homebrew formulae by Paul Haywood-Marx.

## agent-pager

Installs [Pager](https://github.com/haywoodmarx/agent-pager), durable local messaging between agent implementations.

```sh
brew install haywoodmarx/tap/agent-pager
```

The command taps this repository on first use. Upgrade with `brew upgrade agent-pager` and remove with `brew uninstall agent-pager`.
